# CV Database

Single source of truth for building tailored CVs. This is a fictional example (Alex Rivera). Copy the whole `examples/data/` folder to your own data folder and replace these facts with yours.

**Rule:** the database is the master; CVs are *outputs*. When something new happens (new project, metric, cert, course), add it here first, then generate CVs from here.

## Notes
| Note | What it holds |
|---|---|
| [[Profile]] | Contact, education, certifications, awards, languages |
| [[Skills Inventory]] | Every skill ever claimed, with evidence level, where it was used, and when last used |
| [[Experience - Acme Retail]] | Bullet bank for the current role (all wordings + metrics + tags) |
| [[Target Roles]] | Role archetypes: headline, summary, which skills/bullets to lead with, gaps |
| [[CV Version History]] | How the CV evolved + inconsistencies to fix |
